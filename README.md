# Turtle Racing Game

## Description
An interactive betting game built using Python's Turtle graphics. The player places a bet on a colored turtle before the race begins. The turtles then race across the screen using randomized speeds until a winner crosses the finish line.

## Features
- Interactive pop-up dialog to accept user bets.
- Dynamically generates and positions multiple colored turtles.
- Randomized movement speeds for unpredictable race outcomes.
- Announces the winner and checks if the player won the bet.
