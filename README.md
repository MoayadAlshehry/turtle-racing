# Turtle Racing Betting Game

## Description
Interactive betting and race simulator using Turtle graphics.

## Features
- Betting popup dialog
- Randomized turtle movement
- Winner popup

## Technologies
- Python 3.x
- turtle

## Installation
1. Clone the repository:
```bash
git clone https://github.com/MoayadAlshehry/turtle-racing.git
cd turtle-racing
```

## Usage
Run the application:
```bash
python main.py
```
